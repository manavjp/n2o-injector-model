# N2O Injector Model

To predict N2O injector properties from water flow test data and injector geometry

## Layout

* `python/` → Scripts
  * `inputs.py` → Inputs and variables
  * `model.py` → Run model
  * `prediction.py` → Run predictions
* `outputs/` → Generated graphs and CSV data
* `docs/` → Reference literature

Edit `inputs.py` to configure model. Execute `model.py` and `prediction.py`. Outputs are saved in `outputs/`.
